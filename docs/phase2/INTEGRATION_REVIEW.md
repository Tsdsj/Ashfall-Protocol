## Fixture 修正说明

首轮出现六项失败，其中四项来自测试 fixture，不作为产品缺陷报告：

- 两项 Game 测试最初缺少 InputController 的 held 集合；补齐为 Set 后运行正常。
- 两种楼梯旋转的测试最初走得过久，越过顶部地板边缘后开始正常坠落。缩短至停在平台内后，真实上行、下行与旋转均通过，没有修改楼梯业务逻辑。
- 添加 NullEngine/暂停联合测试时，极简 document stub 缺少 removeEventListener，dispose 阶段掩盖了灯光断言；补齐无副作用的事件边界后，才将灯光时钟差异确认为真实产品问题。
- 货架朝向断言随父任务明确修订的物理设计更新：最初侧倒改向，再改为 X 轴倒平；测试不强迫原错误方向，保留“姿态与实际几何/碰撞匹配”的独立验收标准。

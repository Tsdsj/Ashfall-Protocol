# 灰烬协议 · Ashfall Protocol

2037 年 10 月，灰谷自治区。你是一名临时随车维修员，本该到松谷接走 26 名居民，空车的回执却提前盖上了“全部安置”的章。一次翻车后，你必须先活下来，再与诊所护士米拉核对名单，把病历、转运簿、货单和军令连成同一条证据链。

一个运行在浏览器中的单人开放世界生存游戏，使用 TypeScript、Vite 与 Babylon.js。核心玩法和存档在浏览器内运行，本地启动无需游戏后端、数据库或 Docker；目前不包含联机与云存档。

## 启动

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 24。

```bash
npm install
npm run dev
```

打开终端输出的地址（默认 **http://127.0.0.1:5173**）。创建世界后点击“继续探索”，进入第一人称操作。

生产版本：

```bash
npm run build
npm run preview
```

预览默认地址为 **http://127.0.0.1:4173**。生产版本以三个下载队列准备完整离线资源。主菜单显示“离线资源已就绪”后，同一浏览器、同一地址可断网冷启动、读取和保存；失败时可重试。更新后等待资源准备完成再刷新，避免继续运行旧缓存中的脚本。`localhost` 与 `127.0.0.1` 是不同网站来源，存档不互通。

背包：双击使用或装备；穿戴衣物与护甲不占格，但仍计重量，卸装或更换背包需要有可容纳的空间。装备栏可选择已穿戴物并卸下。拖拽时显示可放置/冲突足迹，支持在指定格子转移与部分堆叠合并；Shift + 点击快速转移，R 旋转。物品详情支持拆分、维修、配件安装和快捷栏分配。

建造：先制作组件，再在 B 菜单中选择。鼠标指向位置，R 旋转，E 或左键放置，Esc 取消。结构使用网格对齐，颜色和文字共同提示能否放置。

驾驶：W / S 加速、制动与倒车，A / D 转向，Space 强制制动，停车后 E 下车。上车和下车有动作时间，车门与驾驶状态同步。

搜索、治疗、充电和制作都有进度。背包和手册不会暂停世界，返回后再按 Esc 才会暂停。手电约可连续使用 30 分钟，可在背包中使用蓄电池，或靠近运行中的发电机充电。

切换到其他应用或标签页时，游戏会暂停并清空按键状态。返回后点击“继续探索”恢复鼠标锁定；暂时拒绝锁定时会保留点击恢复入口，不会自动切成右键拖拽。只有在设置中主动开启“兼容鼠标模式”后，才使用右键拖动观察。Esc 释放鼠标后不会立即重新抢占；F11 与 Alt+Tab 保留给浏览器和系统。

## 创造练习

创建世界时勾选“创造练习”。进入游戏后，在手册底部打开“创造物资”，按物品取 1 个或一组；取物仍需背包有空位。F6 切换自由飞行，Space 上升、Ctrl 下降、Shift 加速。飞行忽略碰撞，适合检查场景；退出飞行后恢复正常碰撞。该模式不受伤害、体力无限、负重不减速，建筑组件不消耗材料，但不会自动替你完成剧情任务。模式与飞行状态随存档保存。

## 开始生存

1. 沿公路进入松谷林务站，搜索木柜和救援箱。初始站保证提供食物、医疗、制作材料以及一把空弹匣手枪和匹配弹药。
2. 在背包中装备武器，按 R 装填。枪声会引来感染者；受伤出血后，打开背包使用绷带。
3. 林务站门前可拾取旧帆布、废铁、木材与小石块。2 布料可编 1 绳；2 木材、2 废金属、1 绳可徒手制作铁镐。小石块可裸手采集，持完好铁镐收益更高。装备手斧采集倒木，或对准松树树干砍击：四次有效命中获得木材 ×7。背包放不下时不会消耗最后一次砍伐结果。收集石块与布料，制作篝火和睡袋。
4. 使用刀具处理猎物，在燃烧的篝火旁烹饪。自然水源需要煮沸或净化；雨水收集器可以提供饮水。
5. 睡袋允许安全休息 6 小时并设置重生点。入睡前需要处理出血、补充饮食并清除附近威胁。睡眠会推进燃料消耗和食物腐败。
6. 按日志引导核验林务站广播，调查诊所、军方、工业区和医院的记录。主线按四幕与 Finale 推进，七条幸存者支线可以穿插完成。
7. 结局取决于调查、物资和支线进度。日志会显示尚缺条件；选择后仍可继续生存，但不会重置选择和世界后果。需要完整剧情及分支条件时，阅读 [剧情故事线](docs/STORYLINE.md)。

## 已连接的系统

- 4096 × 4096 米种子世界，256 米分块加载；7 个区域、56 处地点、可进入的建筑与家具。
- 110 种物品，包含三件绑定要塞、研究区与矿场的独特装备/实验制剂；13 种具有独立参数的武器/工具，另有手榴弹，其中 6 种枪械；45 个基础配方和 3 个支线解锁配方、19 种营地设施、22 类搜刮容器。
- 网格背包、旋转、堆叠、拆分、装备、重量、快捷栏、枪械配件、耐久、脏污与卡壳。
- 5 种感染者、掠夺者、鹿、野猪和狼；视线、声音、调查、追踪、搜索、攻击、逃跑和基础掩体行为。
- 弹道速度、重力、衰减、护甲、换弹、枪口照明、后坐力、弹壳、命中反馈、近战和投掷爆炸物。
- 生命、血量、体力、能量、水分、湿度、体温、疲劳、疼痛、出血、骨折、感染、中毒和氧气。
- 制作、狩猎、烹饪、钓鱼、种植、储物、睡眠、基地维修与回收、发电机、接线盒、照明、保温冰箱与雨水收集。
- 可驾驶和维修的皮卡、SUV，车载储物；NPC 话题与物资交换；四幕 + Finale、七条支线、45 条离线中文配音、三种有条件差异的结局。
- 动态昼夜与六种天气状态；自建屋顶避雨，雨水、湿度、保暖与光线相互影响。Director 根据实际战斗和资源压力安排上升、峰值与恢复；营救、停摆车队和罕见无人机残骸都有参与者、阶段与一次性结果。
- IndexedDB 本地存档、自动保存、手动保存、导出和导入；位置、装备、物资、容器、基地、车辆、时间和关键事件都可恢复。

## 画面与性能

优先 WebGPU，不支持时自动使用 WebGL2。提供低、中、高、极高四档质量、分辨率比例、FOV、镜头晃动、分类音量、字幕、字号和键位设置。

第二阶段使用 Quaternius 角色、动作与枪械，Poly Haven 扫描植被、家具和材质，以及独立作者的 CC0 野猪模型；配合原有模块化建筑、程序天空与特效。枪械、四足动物、门、箱盖、冰箱门和手部都有真实动作。中文配音为本地合成，非真人表演。运行时资产由游戏所在站点提供，准备好离线缓存后可从本机读取，不直接请求第三方素材站、外部资源 CDN 或在线语音合成服务。授权和文件校验信息见 [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)。

默认垂直 FOV 为 60°，16:9 画面约对应 91° 水平视野。可在设置中调整分辨率比例、镜头晃动和减少动态效果。

高档包含 PBR、程序化 HDR 环境、级联阴影、SSAO、Bloom、ACES Tone Mapping、雾、风吹植被、天空云层和水面反射。分辨率比例可单独调整，低档降低植被密度、阴影及后处理开销。F3 显示当前 FPS、CPU 渲染/模拟耗时、GPU 计时范围、渲染分辨率和 Draw 数量。其中“GPU 主通道”不是整帧 GPU 总耗时，也不等于显卡占用率。

F4 会暂停游戏渲染约 1 秒，测量当前前台浏览器的轻载 `requestAnimationFrame` 回调频率，再恢复渲染；点击“继续探索”返回游戏。请保持窗口在前台。轻载明显快于游戏时，说明游戏负载仍有优化空间；轻载本身明显低于系统设置时，再检查浏览器、驱动或电源策略。采样值不是显示器规格检测，也不能定位所有性能问题。

游戏未设置固定 60 FPS 上限，但实际帧率受游戏负载、分辨率、硬件与浏览器调度共同影响。当前试玩反馈中曾出现 Windows 设备约 90 FPS，这是特定设备与场景的结果，不是通用性能保证。

## 存档

记录保存在当前浏览器、当前网站地址的 IndexedDB 中。不同浏览器或不同端口的记录相互独立。清除网站数据会删除记录，建议在“读取记录”页面导出 JSON 备份。

v1 存档会自动迁移到 v2，并保留已获得物资、门、营地与记录。新剧情不会凭空认定旧档完成了新增的四方调查。已搜空容器不会刷新。本轮地形调整会在首次读入旧档时迁移营地与地表实体；相连地基及附属构件整体升降，地下楼层保持原位。已有调查进度继续保留；要完整体验改写后的开场，可另建一份生存记录。

游戏每 3 分钟自动保存，并在睡眠、放置营地与重要剧情节点后保存。“保存并返回主菜单”会等待保存成功后退出。普通模式死亡后留下背包并从营地重生；开启“只有一次生命”后无法复活。

## 线上托管

在线版本使用 Sites 的密码入口与私有资源存储，存档仍只在玩家浏览器中。`npm run build:sites` 会把 Worker 与待上传游戏资源分别输出；它不是普通本地预览命令。托管结构、访问保护与发布注意事项见 [Sites 部署说明](docs/hosting/SITES.md)。访问密码和部署密钥不得写入 README、前端资源或 Git。

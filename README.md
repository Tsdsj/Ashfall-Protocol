# 灰烬协议 · Ashfall Protocol

2037 年，灰谷自治区。你在一次运输事故后醒来，身边只有小刀、饮水和一个背包。沿公路探索被遗弃的城镇，寻找补给，建立营地，逐步揭开封锁背后的协议。

一个运行在浏览器中的单人开放世界生存游戏。无需账号、数据库、Docker、Unity 或任何外部游戏服务。

## 启动

需要 Node.js 20.19+ 或 22.12+，推荐 Node.js 24。

```bash
npm install
npm run dev
```

打开 **http://localhost:5173**。创建世界后点击“继续探索”，进入第一人称操作。

生产版本：

```bash
npm run build
npm run preview
```

预览地址为 http://localhost:4173。生产版本以三个下载队列准备完整离线资源。主菜单显示“离线资源已就绪”后，同一地址可断网冷启动、读取和保存；失败时可重试。

背包：双击使用或装备，拖拽时显示可放置/冲突足迹，支持在指定格子转移与部分堆叠合并；Shift + 点击快速转移，R 旋转。物品详情支持拆分、维修、配件安装和快捷栏分配。

建造：先制作组件，再在 B 菜单中选择。鼠标指向位置，R 旋转，E 或左键放置，Esc 取消。结构使用网格对齐，颜色和文字共同提示能否放置。

驾驶：W / S 加速、制动与倒车，A / D 转向，Space 强制制动，停车后 E 下车。上车和下车有动作时间，车门与驾驶状态同步。

搜索、治疗、充电和制作都有进度；Esc 先取消当前操作并保留尚未消耗的材料。背包和手册不会暂停世界，返回后再按 Esc 才会暂停。手电约可连续使用 30 分钟，可在背包中使用蓄电池，或靠近运行中的发电机充电。

如果浏览器拒绝 Pointer Lock，游戏会自动启用兼容视角，仍然可以完成全部玩法。也可以在设置中主动开启“兼容鼠标模式”。Chrome 或 Edge 的普通独立窗口通常能提供更直接的鼠标控制。

## 开始生存

1. 沿公路进入松谷林务站，搜索木柜和救援箱。初始站保证提供食物、医疗、制作材料以及一把空弹匣手枪和匹配弹药。
2. 在背包中装备武器，按 R 装填。枪声会引来感染者；受伤出血后，打开背包使用绷带。
3. 装备手斧采集倒木，收集石块与布料，制作篝火和睡袋。
4. 使用刀具处理猎物，在燃烧的篝火旁烹饪。自然水源需要煮沸或净化；雨水收集器可以提供饮水。
5. 睡袋允许安全休息 6 小时并设置重生点。入睡前需要处理出血、补充饮食并清除附近威胁。睡眠会推进燃料消耗和食物腐败。
6. 在林务站取得补给、建立安全点并接通接收机。调查米拉的病历、军方命令、承包商货单和医院转运簿，再到雷达室解码 ASHFALL。
7. 用访问卡进入地下八米的研究设施，核验四个组织的原始终端，复制完整档案并隔离清理回路。最终控制台提供公开档案、隔离销毁、关闭系统并留下三种选择，各有独立条件。
8. 日志列出七条幸存者支线、录音、配方与已解锁路线；未满足的结局条件可随时查阅。结局后仍可继续生存，选择与任务不会重置。

## 已连接的系统

- 4096 × 4096 米种子世界，256 米分块加载；7 个区域、56 处地点、可进入的建筑与家具。
- 109 种物品，包含三件绑定要塞、研究区与矿场的独特装备/实验制剂；12 种具有独立参数的武器和手榴弹，其中 6 种枪械；44 个基础配方和 3 个支线解锁配方、19 种营地设施、22 类搜刮容器。
- 网格背包、旋转、堆叠、拆分、装备、重量、快捷栏、枪械配件、耐久、脏污与卡壳。
- 5 种感染者、掠夺者、鹿、野猪和狼；视线、声音、调查、追踪、搜索、攻击、逃跑和基础掩体行为。
- 弹道速度、重力、衰减、护甲、换弹、枪口照明、后坐力、弹壳、命中反馈、近战和投掷爆炸物。
- 生命、血量、体力、能量、水分、湿度、体温、疲劳、疼痛、出血、骨折、感染、中毒和氧气。
- 制作、狩猎、烹饪、钓鱼、种植、储物、睡眠、基地维修与回收、发电机、接线盒、照明、保温冰箱与雨水收集。
- 可驾驶和维修的皮卡、SUV，车载储物；NPC 话题与物资交换；四幕 + Finale、七条支线、45 条离线中文配音、三种有条件差异的结局。
- 动态昼夜与六种天气状态；自建屋顶避雨，雨水、湿度、保暖与光线相互影响。Director 根据实际战斗和资源压力安排上升、峰值与恢复；营救、停摆车队和罕见无人机残骸都有参与者、阶段与一次性结果。
- IndexedDB 本地存档、自动保存、手动保存、导出和导入；位置、装备、物资、容器、基地、车辆、时间和关键事件都可恢复。

## 画面与性能

优先 WebGPU，不支持时自动使用 WebGL2。提供低、中、高、极高四档质量、分辨率比例、FOV、镜头晃动、分类音量、字幕、字号和键位设置。

第二阶段使用 Quaternius 角色、动作与枪械，Poly Haven 扫描植被、家具和材质，以及独立作者的 CC0 野猪模型；配合原有模块化建筑、程序天空与特效。枪械、四足动物、门、箱盖、冰箱门和手部都有真实动作。中文配音为本地合成，非真人表演。运行时所有资产均从本地提供，不向素材站、CDN 或语音服务请求资源。授权和文件校验信息见 [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)。

高档包含 PBR、程序化 HDR 环境、级联阴影、SSAO、Bloom、ACES Tone Mapping、雾、风吹植被、天空云层和水面反射。分辨率比例可单独调整，低档降低植被密度、阴影及后处理开销。性能面板显示的是当前设备的实际数据，不能等同于其他 GPU 的基准成绩。

## 存档

记录保存在当前浏览器、当前网站地址的 IndexedDB 中。不同浏览器或不同端口的记录相互独立。清除网站数据会删除记录，建议在“读取记录”页面导出 JSON 备份。

v1 存档会自动迁移到 v2，并保留已获得物资、门、营地与记录。新剧情不会凭空认定旧档完成了新增的四方调查。已搜空容器不会刷新。

游戏每 3 分钟自动保存，并在睡眠、放置营地与重要剧情节点后保存。“保存并返回主菜单”会等待保存成功后退出。普通模式死亡后留下背包并从营地重生；开启“只有一次生命”后无法复活。
